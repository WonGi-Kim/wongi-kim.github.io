# 김원기 · Backend Developer

[포트폴리오](https://wongi-kim.github.io/) · [GitHub](https://github.com/WonGi-Kim) · [기술 블로그](https://velog.io/@wongi-kim/posts) · [상세 포트폴리오 (Notion)](https://ten-tornado-b09.notion.site/18067a27ac7e4f4790dde645fb3bf3d3)

Dr.CBT의 백엔드 개발·운영 경험과 프로젝트를 정리한 개인 포트폴리오입니다.

## 로컬에서 보기

```sh
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다. 별도의 빌드나 패키지 설치 없이 동작합니다.

## 내용 수정

- `index.html`: 소개, 성과, 경력, 프로젝트, 기술 및 링크
- `styles.css`: 반응형 레이아웃, 밝은·어두운 화면, 인쇄 스타일
- `script.js`: 화면 테마, 현재 목차 표시, PDF 저장 시 상세 내용 펼치기
- `favicon.svg`: 브라우저 아이콘

## GitHub Pages

저장소 이름은 `wongi-kim.github.io`입니다. Settings → Pages에서 **Deploy from a branch**, **main / (root)**를 선택합니다. `.nojekyll`이 있어 정적 파일을 그대로 제공합니다.

배포 후 주소: https://wongi-kim.github.io/

PDF 저장 버튼은 브라우저의 인쇄 기능을 사용합니다. 인쇄 대상에서 **PDF로 저장**을 선택하면 프로젝트 상세 내용까지 포함됩니다.
